## 1. アルファ1の新機能

**Nextor 2.1 Alpha 1b** には、Nextor 2.0 のすべての機能に加え、以下の新機能が追加されています。

* **ディスクイメージファイルをドライブレターにマウントする機能**
  * ディスクイメージファイルをドライブにマウントすると、通常の MSX-DOS や MSX BASIC のコマンドおよびツールを使用して、イメージ内のファイルやディレクトリに直接アクセスできるようになります。

> **補足:**  
> Alpha 1b は、Alpha 1 にバージョン 2.0.3 および 2.0.4 で行われたバグ修正と新機能を適用したバージョンです。

## 2. ファイルのマウント方法

ファイルのマウントは、COMMAND2.COM プロンプトから **`MAPDRV.COM`** を使用するか、BASIC プロンプトから **`CALL MAPDRV`** コマンドを使用します。

### MAPDRV.COM を使用する場合（MSX-DOS）
#### 構文：
```text
MAPDRV <ドライブ名:> <ファイル名> [/ro]
```

#### 例（TOOLS.DSK をドライブ G: にマウントする）：
```text
MAPDRV G: TOOLS.DSK
```
* `/ro` オプションを追加すると、**読み取り専用（Read-Only）モード**でマウントされます。このモードのドライブに書き込みを行おうとすると、`Write protected disk` エラーが発生します。

---

### CALL MAPDRV を使用する場合（MSX BASIC）
#### 構文：
```text
CALL MAPDRV("<ドライブ名:>", "<ファイル名>" [,0|1])
```

#### 例（TOOLS.DSK をドライブ G: にマウントする）：
```text
CALL MAPDRV("G:", "TOOLS.DSK")
```
* ファイル名の後に `,1` を追加すると、**読み取り専用モード**でマウントされます。

> **注意：**  
> ディスクイメージファイル自体の属性が「読み取り専用」になっている場合は、オプションで明示的に指定しなくても、常に読み取り専用モードでマウントされます。

---

### アンマウント（マウント解除）の方法
ファイルがマウントされているドライブに対して、別のマッピング（通常のパーティション割り当てなど）を行うか、未割り当て（アンマップ）状態にすることでマウントを解除できます。

```text
MAPDRV <ドライブ名:> U
CALL MAPDRV("<ドライブ名:>", -1)
```

## 3. ルールと制限事項

マウントするディスクイメージファイルは、**サイズが512バイト以上、32メガバイト以下**である必要があります。また、ファイル内にはすでに適切な FAT ファイルシステムが存在している必要があります（マウントしたドライブに対して `FORMAT` コマンドを実行することはできません）。

その他、以下の制限事項があります。

* **パーティションの不可**
  * イメージファイル内にパーティションテーブルを含めることはできません。ファイルシステムはファイルの先頭から開始されている必要があります。
* **同一ドライブでのマウント不可**
  * マウント対象のファイルが存在するドライブ自体に、そのファイルをマウントすることはできません。
  ```text
  MAPDRV A: A:TOOLS.DSK --> エラー
  ```
* **重複マウントの不可**
  * 同一のファイルを同時に2つのドライブにマウントすることはできません。
  ```text
  MAPDRV B: TOOLS.DSK
  MAPDRV C: TOOLS.DSK --> エラー
  ```
* **再帰マウントの不可**
  * マウントされたイメージの中にあるイメージファイルを、さらにマウントすることはできません。
  ```text
  MAPDRV B: TOOLS.DSK
  MAPDRV C: B:FILE.DSK --> エラー
  ```
* **マウント元ドライブのマッピング変更不可**
  * マウントされているファイルが存在する元のドライブについて、マッピング状態を変更することはできません。
  ```text
  MAPDRV B: A:TOOLS.DSK
  MAPDRV A: U --> エラー
  ```
* **マウント中ファイルの操作制限**
  * マウントされている元のファイルを開いたり、変更（名前変更、移動、削除、上書き、属性変更）したりすることはできません。
  ```text
  MAPDRV B: TOOLS.DSK
  TYPE TOOLS.DSK --> エラー
  ECHO HELLO > TOOLS.DSK --> エラー (下記の「既知のバグ」を参照)
  REN TOOLS.DSK X.DSK --> エラー
  MOVE TOOLS.DSK SOMEDIR\ --> エラー
  DEL TOOLS.DSK --> エラー
  ATTRIB +R TOOLS.DSK --> エラー
  ```

## 4. ファンクションコールの変更点

### `_MAPDRV` (7Ch) の拡張
ファイルをマウントできるように拡張されました。パラメータは以下の通りです。

* **B** = `3`
* **HL** = ファイル名へのパス、またはFIB
* **D** = マウントモード
  * `0`: デフォルトマウント（ファイルに読み取り専用属性がない限り書き込み可能）
  * `1`: 強制読み取り専用マウント

---

### `_GDLI` (79h) の変更
ファイルがマウントされているドライブに対して実行した際、データバッファに以下の情報が返されるようになりました。

| オフセット | サイズ | 内容 |
| :--- | :--- | :--- |
| **+0** | 1バイト | `3` |
| **+1** | 1バイト | マウントされたファイルが存在するドライブ（0 = A:, 1 = B:, など） |
| **+2** | 1バイト | フラグ（`1`: 読み取り専用モード、`0`: 読み書き可能） |
| **+3** | 1バイト | `0` (将来の拡張用) |
| **+4** | 最大13バイト | 表示可能形式のファイル名（最大12文字 ＋ 末尾の `0`） |

> 詳細は「Nextor プログラマーズリファレンス」をご参照ください。

## 5. 新しいエラーコード

本バージョンより、2つのエラーコードが追加されました。

* **`File is mounted`**（`.FMNT` / DOSエラー: `B2h` / BASICエラー: `80`）
  * マウント中のファイルを開こうとしたり、変更しようとしたりした場合など、許可されていない操作を行った際に発生します。
* **`Bad file size`**（`.BFSZ` / DOSエラー: `B1h` / BASICエラー: `81`）
  * マウントしようとしたファイルのサイズが、512バイト未満または32メガバイトを超えている場合に発生します。

---

## 6. 既知のバグ

* **マウント中ファイルの上書き制限の不具合**
  * 「ファイルハンドルの作成」ファンクションコール（`_CREATE`, 44h）を使用した上書き（例：`ECHO HELLO > TOOLS.DSK` など）を行った場合、エラーにならずに上書きが成功してしまいます。本来であれば `File is mounted` エラーが返されるべき箇所です。

---

## 7. その他の有用な情報

> **警告：**  
> 本ソフトウェアはアルファ版です。十分にテストされておらず、バグが含まれている可能性があります。使用前に必ずデータのバックアップを行ってください。

> **警告：**  
> ファイルをマウントした後は、そのファイルが保存されているメディア（SDカード等）を抜いたり交換したりしないでください。データの消失や、想定外の挙動を引き起こす原因になります。

### DRVINFO コマンドの対応
アップデートされた `DRVINFO.COM` または `CALL DRVINFO` コマンドを使用すると、マウントされているファイル名と元の保存先ドライブが表示されます。

```text
Drive G: is assigned to:
File TOOLS.DSK on drive A: (read-only)
```

### 空のディスクイメージを作成する方法
空のディスクイメージファイルを作成する際は、KonamimanのMSXサイトで公開されているツール **`NestorDiskImageCreator`** を使用すると便利です。
* [NestorDiskImageCreator のダウンロード](http://konamiman.com/msx/megascsi/ndicreat.lzh)

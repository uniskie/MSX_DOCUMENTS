# Nextor ドキュメント

Nextor向けに以下のドキュメントが用意されています。

* [スタートガイド](Nextor%202.1%20Getting%20Started%20Guide.md): エミュレータまたは実機のいずれかを使用して、Nextorを使い始めるためのステップバイステップのチュートリアルです。

* [ユーザーマニュアル](Nextor%202.1%20User%20Manual.md): 一般ユーザー向けのマニュアルです。NextorがMSX-DOS 2の機能をどのように拡張しているかを説明し、Nextorのツールおよび内蔵コマンドのリファレンスを掲載しています。

* [プログラマーズリファレンス](Nextor%202.1%20Programmers%20Reference.md): アプリケーション開発者向けのリファレンスです。Nextorで実装された新しいファンクションコールや、新規および拡張されたDisk BASICコマンドのリファレンスを掲載しています。

* [ドライバー開発ガイド](Nextor%202.1%20Driver%20Development%20Guide.md): Nextor用のデバイスドライバーを開発する場合に必要となります。

* [ドライバーのスケルトン（骨格コード）](DRIVER_ASM.md): Nextor用のデバイスドライバーを開発する際のベースとして使用します。

また、参考資料として（Nextorにも関連する）MSX-DOS 2用の以下のドキュメントも提供されています。

* [MSX-DOS 2 プログラムインターフェース仕様書](DOS2-PIS.md)

* [MSX-DOS 2 ファンクションコード仕様書](DOS2-FCS.md)
